# 02 · 架构与技术选型

> 口径来源：`data/README.md` §4（人类可读唯一定义处）+ `data/ruleset.v1.json`（机器可读镜像）。
> 本文只描述结构与边界，**不写第二份阈值**。

## 一、分层

| 层 | 目录 | 职责 | 允许依赖 | 禁止 |
|---|---|---|---|---|
| L0 口径 | `data/ruleset.v1.json` | 全部阈值、版本号、白名单 | 无 | 不含任何逻辑 |
| L1 核心 | `src/core/**` | 纯函数：解码、解析、规则、报告、修复 | L0 与自身 | 不碰 DOM、不发网络、不读时钟、不读 locale |
| L2 编排 | `src/core/pipeline.js` | 把 L1 串成一次体检 | L1 | 不做判定、不渲染 |
| L3 界面 | `src/ui/**` | 拖放、渲染、导出 | L2 | 不实现规则、不出现阈值字面量 |
| L4 构建 | `tools/**` | 内联构建、门禁、数据生成 | 读 L0–L3 | 不进产物 |

依赖方向是单向的。`tests/architecture.test.mjs` 用源码扫描锁住三条：
`src/core/**` 不得出现 `document.` / `window.` / `fetch(` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` / `Date.now` / `new Date`；
`src/ui/**` 不得直接 `require("core/rules/…")`；
`src/**` 不得出现口径阈值字面量（由 `tools/check-ruleset.mjs` 的区分性字面量扫描承担）。

## 二、构建（单文件内联）

- 源码形态：每个模块用 `SP.define(name, deps, factory)` 注册（经典脚本，非 ESM），
  由 `src/core/namespace.js` 提供最小模块注册表。这样浏览器与 Node 测试**共用同一条执行路径**。
- `tools/bundle.mjs` 按**显式清单** `SOURCE_FILES` 顺序拼接；清单必须与 `src/**/*.js`
  实际集合逐项相等（多一个、少一个都判红，防"新增文件没进产物"）。
- `data/ruleset.v1.json` 在构建时注入为 `SP.define("data/ruleset", [], () => …)`；
  源码里不出现阈值字面量。
- 模板 `src/ui/index.html` 用 `/*{{CSS}}*/` 与 `/*{{JS}}*/` 两个占位符；
  构建断言各出现**恰好一次**，替换后断言占位符为零。
- 输出 `dist/subtitle-preflight.html`：单文件、LF 行尾、无时间戳、无本机路径、无外部资源。
- `node tools/build.mjs --check` 重新渲染并与磁盘产物逐字节比较；CI 跑这条。
- 同一输入两次构建逐字节一致（`tests/build.test.mjs` 锁）。

## 三、数据契约

### 3.1 cue 模型（L1 唯一中间表示）

```json
{
  "index": 1,
  "startMs": 0,
  "endMs": 1200,
  "textLines": ["第一行", "第二行"],
  "textLineNumbers": [3, 4],
  "format": "srt",
  "sourceLine": 1,
  "endLine": 4,
  "timeLine": 2
}
```

- `sourceLine` / `endLine`：cue 块的起止行（1-based）。
- `timeLine`：时间码所在行，时间类 finding 的 `line` 取它；文本类 finding 取 `sourceLine`。
- 行号映射表由模块 ① 产出，后续模块只消费，不重算。

### 3.2 finding

```json
{
  "ruleId": "timing.overlap",
  "severity": "error",
  "line": 8,
  "field": "startMs",
  "expected": ">= 3400",
  "actual": "3200",
  "message": "本条起点早于上一条结束"
}
```

### 3.3 报告

键序固定：`schemaVersion` → `rulesetVersion` → `inputSha256` → `summary` → `findings` → `fixes` → `skipped` → `capabilities` → `diagnostics`。
`summary` 的键序固定为 `total` → `bySeverity` → `byRule` → `whitelist`（`whitelist` 是 M5 新增：
白名单命中次数，**命中白名单不是违规**，故不进 `findings[]`）。
`report.schemaVersion` 因此由 `1` 升到 `2`（报告结构变了），`report.rulesetVersion` 保持 `1`（M5 未改任何阈值数值）。
`capabilities` 是本题扩展键：显式声明本轮已实现/未实现的解析器、规则、导出格式、修复、漂移拟合。
报告**不含**时间戳、随机 ID、本机路径。

三格式（JSON / Markdown / CSV）**共用同一份 findings 数组**（单一渲染源）：
- JSON：2 空格缩进、结尾换行。
- Markdown：按 severity 分组，每条含 `第 N 行` 与原文片段（截断 60 字符，超出加 `…`）。
- CSV：列固定 `ruleId,severity,line,field,expected,actual,message`，按 **RFC 4180** 转义（CRLF 行尾）。

## 四、技术选型与弃选

| 选择 | 结论 | 理由 |
|---|---|---|
| 运行时依赖 | **零** | 断网可用、双击即用；CI 不需要 install 步骤 |
| 构建器 | **自写 `tools/bundle.mjs`** | 只做拼接与注入，行为可读、可测试、逐字节确定 |
| 框架（React/Vue） | **弃** | 增加体积与构建复杂度，界面只有拖放 + 表格 + 下载 |
| ESM + 打包器 | **弃** | 单文件内联需要额外解析；`SP.define` 注册表更小且 Node/浏览器同路径 |
| WASM / 模型 | **弃** | 四类规则均为字符串与时间戳运算（见 plan/01 §6） |
| CDN / 外部字体 | **弃** | 违反零网络请求硬约束 |
| 本地服务端口 | **弃** | 违反"双击打开即用"的唯一下载形态 |
| TypeScript | **弃** | 引入编译链；用 JSDoc 注释 + 测试替代 |

## 五、错误与降级

| 情形 | 行为 | 可见性 |
|---|---|---|
| 未知格式 | 不解析，返回 `parser.unsupported` 诊断 | 文件卡片 + 报告 `skipped[]` |
| 已声明但未实现的解析器 | 返回 `parser.not_implemented`，**不返回空成功**（当前三解析器均已实现，此路径仅在新增解析器时启用） | 同上 |
| 时间码无法解析 | 跳过该块，产出 `parse.unparsable-timecode` 诊断 | 同上 |
| 编码严格解码失败 | 回退 GBK；再失败则 UTF-8 替换解码并标 `lossy` | 文件卡片徽章 + 报告诊断 |
| 未实现的规则 | 写入 `skipped[]`（`reason: "not_implemented"`）——**当前已无此情形**（四域全实现） | 报告 + 界面"未执行检查"折叠区 |
| 缺媒体时长 | `timing.past-media-end` 标 `skipped` | 报告 `skipped[]` |
| 修复不可执行 | `skipped[]` 里 `{kind:"fix", reason:"no_fixable_finding"}`（**执行结果**，不是"未实现"） | 报告 + 界面"已应用的修复"折叠区（为空则折叠） |

**硬纪律**：任何"没做"都必须以数据形式出现在产物里，不能只写在文档里。
反之亦然——**已经做了就不能再声明"没做"**：M5 实现卫生/修复/MD/CSV 之后，
`capabilities` 与 `skipped[]` 里的 `not_implemented` 已全部撤下。

## 六、确定性设计

1. 所有数值比较走**定点整数**（字符数 × 1000 / 毫秒），不用浮点直接比较。
2. findings 按 `(line, ruleId)` 排序；`summary.byRule` 的键按字典序输出。
3. JSON 导出用固定缩进 2 空格 + 结尾换行；对象键按上文固定顺序插入。
4. 不读时钟、不读 locale、不读 `Math.random`。
5. 构建产物无时间戳、无绝对路径；`--check` 逐字节比较。
6. 解码优先 BOM，其次 UTF-8 严格，最后 GBK；回退结果必须显式标注。

## 七、隐私边界

- 文件通过 File API 在浏览器内读取，**不经过任何网络**。
- 产物静态断言：无 `<script src>`、无 `<link>`、无 `@import`、无 `url(http…)`、无 `fetch(`/`XMLHttpRequest`/`WebSocket`/`sendBeacon`。
- 允许的唯一外链形态是用户主动点击的 `<a href>`（不是资源加载）。
- 不上传、不遥测、不内置字幕库。
